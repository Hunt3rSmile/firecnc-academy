# Формат лицензии FCNC1 v1

Токен: `FCNC1.<payloadBase64Url>.<signatureBase64Url>`. `.fcnclic` содержит тот же UTF-8/ASCII токен и необязательный завершающий перевод строки. Внутренние пробелы не нормализуются. Алгоритм фиксирован: Ed25519 из Node crypto, `sign/verify(null, bytes, key)`; иных алгоритмов или полей alg нет.

Подписываемые байты: ASCII `FireCNC-License-v1`, один нулевой байт `00`, затем **исходные ASCII-байты payloadBase64Url**. JSON повторно не сериализуется. Подпись — ровно 64 байта. Base64url без padding, каноническая обратная кодировка обязательна. Общий предел 12000 байт.

Payload: строгий объект без неизвестных полей и повторных ключей. UTF-8 декодируется с fatal=true. Ограничения разбора: глубина ≤6, ≤150 узлов; escaped имена полей также проверяются на дубликаты. `__proto__` не меняет прототип парсера. До подписи допускается использовать только keyId для выбора из встроенного ограниченного словаря, без путей/URL.

| Поле | Допустимое значение |
|---|---|
| version, productId | 1, `firecnc-academy` |
| kind | `offline` или `lease` |
| licenseId | 8–64 символа: латинские буквы, цифры, дефис; issuer использует UUID |
| keyId | Первые 16 hex символов SHA-256 от DER SPKI открытого Ed25519 ключа |
| licensedTo | Непустое отображаемое имя до 160 символов |
| edition | student, teacher, lab |
| modules | 1–7 уникальных известных имён из contracts/MODULES |
| issuedAt, notBefore | Целые Unix-секунды UTC 0…4102444800, issuedAt ≤ notBefore |
| expiresAt | null только для offline либо целое время > notBefore; граница now ≥ expiresAt уже недействительна |
| binding | null либо `{installationHash: 64 lowercase hex}` |
| activationId | UUID, обязателен у lease и запрещён у offline |

Для lease также обязательны срок и привязка. Схема проверки lease предусмотрена, но сервер выдачи/продления и клиент онлайн-активации пока отсутствуют. Lab зарезервирована в схеме и матрице; CLI её выпуск блокирует до реализации учёта мест в этапе E. Floating-лицензия не заявляется.

Матрица в одном месте: `packages/contracts/src/index.ts`. Student по умолчанию theory, turning, milling, measurements, exams; Teacher дополнительно teacher; Lab все семь, включая cadcam. Фактические права — проверенный список, не название редакции. Часть модулей относится к ещё не реализованным этапам и не создаёт фиктивных действий в UI.

Сначала проверяются кодировка, ограниченный JSON и выбор ключа; затем Ed25519, строгая схема, даты и привязка. При неактивном статусе модули не выдаются. Для истёкшего корректно подписанного токена разрешено отображать подтверждённые сведения, но операции проверяют `status === active` и наличие модуля. Повреждённый импорт не заменяет сохранённую лицензию.

installationHash = SHA-256 UTF-8(`FireCNC-Installation-v1\0` + random UUID установки). UUID создаётся один раз в БД; сохраняется при нормальном обновлении. Это идентификатор установки, не аппаратный HWID. Восстановление старого диска/клонирование администратором не предотвращаются. Откат часов более 300 с от последнего наблюдения блокирует новые срочные действия с объяснением; доверенного времени полностью офлайн нет.

Публичный вектор: `tests/fixtures/public-license-vector.json`. В нём токен, публичный ключ, payload, фиксированное now. Закрытый ключ вектора не сохранён. Тест сверяет проверку и отсутствие доверия по умолчанию. Рабочий открытый ключ владельца хранится в config/trusted-keys.json. Release-build дополнительно отвергает ключ публичного вектора и текущий `.local` development-ключ. В клиенте нет master key, issuer, закрытых ключей или переключателя разблокировки.

Офлайн бессрочный токен нельзя мгновенно отозвать дистанционно. Ротация новых ключей требует сборки клиента с новым публичным ключом (до восьми ключей), затем перевыпуска лицензий. Отключение старого ключа при обновлении затрагивает только обновлённые клиенты. Данные и экспорт результатов сохраняются при истечении или недействительной лицензии.
