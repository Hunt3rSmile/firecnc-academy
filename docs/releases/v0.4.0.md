# FireCNC Academy 0.4.0

Письменная практика по материалам занятий KELLER SYMplus / PAL: 14 заданий вместо выбора готового ответа, включая полную 25-кадровую программу детали. Все 60 фотографий распознаны Gemini 3.8 Flash High через agy и доступны локально вместе с текстом, увеличением и поиском. Черновики, разбор ошибок по кадрам и история разделены по профилям.

В настройках лицензии появился отдельный API-ключ DeepSeek. Помощник объясняет условие, текущий код и результат локальной проверки, работает также под редактором/симулятором. Ключ защищён safeStorage ОС; при недоступном защищённом хранилище доступен только сеанс без записи ключа на диск. Есть проверка подключения, удаление ключа и отмена запроса.

PAL проверяется отдельно от FireCNC DIN. Проверка письменных кадров не моделирует материал и столкновения. Теоретические экзамены, прежние результаты и действующие лицензии сохранены.

Проверено: TypeScript, 204 unit-теста и 17 Electron E2E. В сценариях проверены ввод решения, ошибки команд, фото без внешней сети, десятичная запятая, восстановление черновика, история и разделение профилей. Реальный ответ DeepSeek Flash получен через официальный API.

Linux-пакет 0.4.0-2 автоматически выбирает gnome-libsecret в Hyprland. Проверены шифрование реального ключа, восстановление после перезапуска и настоящий ответ помощника на условие задания; временный файл с ключом удалён. Пакет и AppImage прошли автономную приёмку.
