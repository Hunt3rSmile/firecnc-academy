# FireCNC Academy 0.2.0

Первая публичная учебная версия для Windows x64 и Linux x64.

## Скачать

- **Windows:** `setup-x64.exe` — установщик; `portable-x64.exe` — переносимый вариант.
- **Linux:** `.AppImage` — самостоятельное приложение; `.tar.gz` — распаковываемая сборка.
- **Omarchy / Arch Linux:** локальный пакет `.pkg.tar.zst`, если он приложен, либо `bin/install-omarchy` из исходников.
- Контрольные суммы файлов — `SHA256SUMS.txt`.

## Работает

6 уроков, 12 вопросов, вводная проверка с разбором и сохранением прогресса. Редактор Monaco; собственный учебный DIN/ISO; дуги, G54, 2D/3D и реальное снятие материала в моделях r/Z и 2.5D. Шесть практических примеров, проверки столкновений и воспроизведение по кадрам. Офлайн-лицензии Ed25519 и отдельная утилита владельца.

Добавлена проверка новых выпусков на GitHub: при запуске установленного приложения и каждые 6 часов, а также вручную в настройках. Можно отключить автоматическую проверку. Обновления скачиваются со страницы GitHub и устанавливаются пользователем. Учебные данные и ключ лицензии не отправляются на сервер обновлений.

В сборках есть открытый ключ владельца; ранее выданные им лицензии принимаются. Приватные ключи и реальные файлы лицензий в исходную и клиентскую поставку не включены.

## Границы версии

Завершены A/B, C частично. Заготовки и инструменты пока фиксированы; оценивание практики использует контрольные пробы. Полные экзамены, измерительные приборы, преподаватель, сервер активации и CAD/CAM ещё не реализованы. Приложение не управляет реальным станком. Это собственный учебный профиль, не промышленная эмуляция FANUC / PAL / SINUMERIK.

У Windows-файлов нет Authenticode-подписи владельца; SmartScreen может показывать предупреждение. Установка новых версий выполняется вручную. Сохраните открытый проект перед обновлением; используйте резервную копию из настроек.
