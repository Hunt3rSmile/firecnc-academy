# FireCNC Academy 0.4.1

Письменная практика PAL, помощник DeepSeek и новый размерный тренажёр G1.

- **14 письменных заданий по KELLER SYMplus / PAL.** Нужно написать программу или расчёт. Есть проверка по кадрам, пояснения и итоговая программа детали на 25 кадров.
- **60 фотографий с занятий** с распознанным текстом, поиском и увеличением. Материалы доступны без интернета.
- **Новый тренажёр координат G1:** светлый чертёж, крупные диаметры и продольные размеры, фаски и переходы 45°, цветные узловые точки. Каждая новая деталь меняет длины, диаметры, число ступеней и переходы.
- **Два поля X/Z и управление по Enter.** Неверный ответ можно исправить; черновики, попытки и прогресс сохраняются по профилям. G90 выбран по умолчанию, G91 и смешанный режим доступны в настройках.
- **DeepSeek в «Настройки и лицензия».** Помощник видит выбранное задание, введённое решение или текущую программу и объясняет ошибки и команды. API-ключ пользователь добавляет отдельно; в исходники и сборки он не входит. В Hyprland автоматически выбирается защищённое хранилище gnome-libsecret.

[Посмотреть новый экран координат](https://github.com/Hunt3rSmile/firecnc-academy/blob/v0.4.1/docs/screenshots/coordinates.png) · [Как работают задания и DeepSeek](https://github.com/Hunt3rSmile/firecnc-academy/blob/v0.4.1/docs/CLASSROOM_RU.md)

Проверка письменных кадров PAL оценивает команды и координаты, без расчёта материала и столкновений. Редактор и 3D-симулятор используют отдельный учебный профиль FireCNC DIN. Для запросов DeepSeek нужны интернет и собственный API-баланс; локальная проверка задач работает автономно.

Локально проверены TypeScript, 207 модульных тестов и 17 Electron E2E, а геометрия — на 300 seed. Linux-пакет и установленная версия проверены; действующие лицензия, учебные данные и зашифрованный ключ сохраняются при обновлении. Файлы GitHub Release публикуются после проверки сборок Windows и Linux в CI.

Скачайте установщик или portable для Windows либо AppImage/архив для Linux. Контрольные суммы файлов находятся в `SHA256SUMS.txt`.
