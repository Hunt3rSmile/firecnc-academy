# FireCNC Academy 0.3.0

Учебный выпуск для Windows x64 и Linux x64.

- 24 собственных урока, 120 вопросов, 20 практических заданий с размерными схемами и проверкой фактического материала.
- Тренировка точек G90/G91 со случайным режимом для каждой точки, сохранением попытки и разбором. Токарное X — диаметр.
- Рабочая область стала проще: основное действие «Запустить», дополнительные панели раскрываются по необходимости. Вращаются заготовка/патрон либо фреза; пауза и M5 останавливают показ.
- Штангенциркуль и микрометр с согласованной математической шкалой, тренировкой и контрольной серией.
- Воспроизводимые экзамены восьми типов, автосохранение/восстановление таймера, разбор, JSON и PDF. Таймер идёт при закрытой программе.
- Мастерская с узлами станка, видами/разборкой и последовательностью наладки. Локальные профили преподавателя, собственные вопросы/тесты/простые задания и версионируемые пакеты.
- Базовый CAD/CAM: отрезки/дуги, размеры/проверка контура; четыре ограниченные операции с проверкой общей симуляцией и независимой аналитикой.
- Отдельный сервер коротких ключей, Lab с учётом установок, подписанные автономные разрешения, продление и деактивация. Офлайн-файлы продолжают работать независимо.
- Проверяемое восстановление SQLite с защитной копией, экспорт диагностики без секретов и сохранение данных при обновлении.

Старые лицензии сохраняются. Для нового CAD/CAM нужен явный модуль cadcam в подписанной лицензии; пароль преподавателя не добавляет модулей.

Файлы: setup — установка Windows, portable — запуск без установки, AppImage — Linux, tar.gz — распакованный Linux runtime. Node.js на учебном ПК не нужен. SHA256SUMS содержит контрольные суммы.

Это FireCNC DIN v1, без промышленной эмуляции PAL/FANUC/SINUMERIK и без управления оборудованием. Точение осесимметричное, фрезерование 2.5D сверху плоской фрезой. CAD/CAM пока содержит одну операцию на стандартной заготовке; CAM токарного профиля принимает монотонные отрезки. Вращение замедлено 20×, шаги воспроизведения не являются точным показом времени подачи. Все ограничения — SIMULATION_LIMITS.md и CNC_PROFILE.md.

CI проверяет Windows Server 2025 и Ubuntu 22.04, включая реальные процессы Electron, пакеты, portable/AppImage и сохранение данных при NSIS-переустановке. Ручная Windows 11, настоящий DPI 125–150% и длительные GPU-испытания остаются отдельной приёмкой. Файлы не подписаны сертификатом Authenticode. Полный объём A–F не объявляется принятым без этих проверок.
