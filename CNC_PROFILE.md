# FireCNC DIN v1 — точная семантика

Собственный учебный профиль на основе открыто описанной геометрии RS274/NGC. Это **не** совместимость со всей LinuxCNC, PAL, FANUC или SINUMERIK. Дополнительных профилей в списке доступных систем нет.

| Слова | Поведение |
|---|---|
| G0 | Прямая, идеальная скорость 3000 физических мм/мин. Пересечение материала — авария, без снятия. |
| G1 | Прямая с F в физических мм/мин. Время = длина/F × 60, без динамики. |
| G2, G3 | Часовая/против часовой дуга, вид со стороны положительной нормали. Только плоская дуга, без винтовой составляющей. |
| G17 | Только фрезерный профиль: упорядоченные оси (X,Y), нормаль +Z. |
| G18 | Только токарный профиль: упорядоченные оси (Z,X), нормаль +Y. |
| G21 | Только мм. Другие единицы не принимаются. |
| G90/G91 | Абсолютная конечная точка относительно G54 / физическое приращение текущей точки. Это НЕ токарный цикл FANUC G90. |
| G54 | Единственное смещение, задаётся параметрами проекта, не G10. |
| F | Положительная физическая подача ≤10000 мм/мин. Режим фиксирован; G94/G95 не поддерживаются. |
| S | Положительные обороты ≤30000 об/мин. Без G96/G97 и постоянной скорости резания. |
| T при точении | Ровно 4 цифры NNCC, сохраняются ведущие нули. Слоты 01–08, CC должен совпадать с NN; геометрические поправки нулевые. Смена немедленная, без перемещения. |
| T и M6 при фрезеровании | T выбирает слот 1–8, M6 устанавливает выбранный инструмент. В мастерской v1 существуют геометрии только 1 и 2; остальные вызывают остановку симуляции. |
| M3/M4/M5 | CW/CCW/off. Для M3/M4 заранее необходим S. Правые инструменты доступного сценария режут только при M3. |
| M8/M9 | Состояние СОЖ; тепловая/силовая модель не меняется. |
| M0 | Событие остановки воспроизведения; следующий запуск продолжает следующий кадр. |
| M2/M30 | Конец без перемотки позиции; шпиндель выключается, СОЖ выключается. Исполняемые слова после него — ошибка. |
| N, (…), ; | Необязательный целый номер кадра первым словом; ненестированные комментарии; остаток строки после `;` — комментарий. |

G0–G3, G17/G18, G90/G91 и соответствующие M-группы допускают только одну команду каждой группы в кадре. Повтор G0 G0 тоже конфликт. Повтор оси/параметра отклоняется. Смена инструмента и остановка с движением в одном кадре запрещены. S/F и изменения станка того же допустимого кадра применяются до движения. При ошибке **никакая** часть кадра не применяется.

Числа: `12`, `12.`, `.5`, `+.5`, `-0.25`; регистр и пробелы несущественны. В программе десятичный разделитель — точка; экспоненты, выражения, переменные, `%`, block delete, eval и подпрограммы не принимаются. Числовой ответ в учебном контенте, в отличие от G-кода, допускает запятую.

## Системы координат

Машинные/физические позиции в core — `{x,y,z}` в мм. Для точения x — **радиус**. Рабочая физическая позиция = машинная − offset; абсолютная команда = рабочая физическая + offset. При точении текстовая X делится на 2 и в G90, и в G91. Смещение G54.x — физическое радиальное; оно не делится повторно. Y в токарной программе запрещена. Начальная машинная позиция: точение (25,0,5), фрезерование (−10,−10,10).

Материал и крепление закреплены в машинных координатах. G54 изменяет траекторию относительно них, не переносит всю мастерскую. При нулевом G54 токарный торец Z0 и фрезерная верхняя поверхность Z0 совпадают с рабочим нулём. Ввод неверного G54 способен оставить материал необработанным либо вызвать аварию.

Сцена Three.js: токарная `(sceneX,sceneY,sceneZ)=(Z,r cosθ,r sinθ)`; фрезерная `(X,Z,−Y)`. Преобразования сцены не используются для проверки обработки. Панель координат показывает рабочие значения, X при точении обратно умножается на 2. Измерительные пробы привязаны к исходной заготовке в машинной системе.

## Дуги

I/J (G17) и K/I (G18) — **всегда относительные смещения центра от начала**, в физических мм, независимо от G90/G91. I при точении — радиальное расстояние и не делится на 2. Неиспользуемый компонент центра запрещён. R и центр нельзя смешивать.

R>0 — дуга не более 180°, R<0 — не менее 180°. Для полуокружности обе формы совпадают. Полная окружность через R отклоняется; через смещение центра допускается. Нулевой радиус, невозможная хорда, несовместимые радиусы начала/конца, винтовая дуга или уход в отрицательный рабочий радиус отклоняются.

Параметр chordError по умолчанию 0,02 мм, диапазон 0,001–0,5. Половина бюджета отведена прогибу хорды; несовпадение радиусов не более min(0,01, chordError/2). Угол сегмента рассчитывается из радиуса и прогиба, дополнительно ограничен π/4. Длительность дуги определяется аналитической длиной r·угол, а не суммой хорд.

Лимиты: 200000 символов, 5000 строк, 40 слов/кадр, 50000 сегментов, координаты до ±10000 мм. Симулятор дополнительно ограничивает перемещения: X/Y −100…300, Z −150…300 мм. Структурированная ошибка содержит код, строку, столбец, объяснение и исправление.

Не поддерживаются: G20, G94/G95, G96/G97, G40/G41/G42, G43, циклы, резьба, подпрограммы, переменные, G53, другие рабочие смещения и промышленные инструментальные коррекции. Такие команды не игнорируются.

Тренажёр координат 0.3 использует эту же собственную семантику: X при точении задаёт диаметр и в G90, и в G91. Например, радиальное изменение 3 мм на фаске даёт изменение X на 6 мм. Упражнения X/Y и X/Z аналитические, без сетки снятия материала, допуск ответа 0,001 мм. Семантика PAL с фотографий или иных промышленных стоек не заявляется. Режимы каждой попытки и чертёж сохраняются; новая точка отсчитывается от правильной предыдущей точки чертежа, даже если предыдущий ответ был ошибочным.
