## Работающие сценарии

| Этап | Реализовано и проверено в исходниках |

| B | Выпуск/проверка/импорт/экспорт офлайн Ed25519 FCNC1, Student/Teacher, устойчивая привязка к установке, проверки модулей в main/IPC; подделка не заменяет действующий файл. Закрытого ключа в клиенте нет. |
| C | Оба учебных интерпретатора G0–G3/G54, реальный r/Z-материал и 2.5D-поле высот, инструменты/держатели/крепление, столкновения и возврат с восстановлением материала, 20 заданий (10+10), размерные схемы и независимая проверка полной формы. |
| D | 24 собственных урока (12+12), 120 разных вопросов (60+60), восемь типов ответов, шесть экзаменов, снимки состава/ответов/порядка, таймер и восстановление, разбор/повторение, математические штангенциркуль и микрометр, JSON/PDF. |
| E | Локальные профили, пароль преподавателя scrypt без пароля по умолчанию, редактор вопросов/тестов/простых геометрических заданий, транзакционные версионируемые пакеты; отдельный сервер коротких ключей, Lab/места/lease/renew/deactivate; базовый CAD/CAM четырёх операций с проверкой результата. |
| F | Конфигурация Windows/Linux, ASAR и все три Node Workers, NSIS/portable/AppImage, тесты установки/обновления/удаления, резервное копирование/восстановление и диагностика. Актуальный CI прошёл обе платформы; ручная Windows 11/DPI остаётся открытой. |

Рабочая область стала спокойнее: основное действие «Запустить», дополнительные настройки раскрываются по необходимости, боковое меню в симуляторе/мастерской/CAM компактное. Заготовка и патрон вращаются при токарном M3/M4; при фрезеровании вращается фреза. Пауза/M5 останавливают показ. Вращение замедлено 20×, расчёт материала не зависит от FPS.

Тренажёр G90/G91 использует собственные размерные схемы: режим выбирается по seed отдельно для каждой точки, вводятся начальная/промежуточные/конечная точки, принимаются запятая и точка. Состав попытки сохраняется. Снимки KELLER использованы как описание учебного сценария, их интерфейс и материалы не копировались.

CAD: отрезки/дуги, привязка, перемещение точек, точные размеры, отмена, разрывы/самопересечения. CAM: наружный линейный монотонный профиль, торцевание, плоскость, прямоугольный карман со скруглениями по фрезе. Одна операция в документе и стандартные заготовки; дуги CAD пока не преобразуются в произвольный токарный профиль CAM. Все сгенерированные программы проходят общий интерпретатор, симуляцию, аналитику всей формы и независимый объём.

AppImage действительно запускался из кириллического пути с повторным открытием данных (режим extract-and-run; FUSE-mount отдельно не проверен).

Это короткий воспроизводимый замер на одной машине, не гарантия отсутствия любой утечки или 60 FPS. Данные и конфигурация: TESTING.md, docs/benchmarks/.

## Следующая конкретная задача

Следующая задача: ручная приёмка Windows 11/DPI на учебном ПК; следующее функциональное расширение — несколько последовательных CAM-операций. Omarchy обновлён до **0.3.0-1**: перед заменой создан согласованный снимок; проверены неизменность ID, лицензии, профилей и всех счётчиков, quick_check=ok. После запуска прогресс/экзамен сохранены, окно нативное Wayland (xwayland=false), pacman подтверждает 178 файлов без пропусков. Установленный ASAR совпадает с проверенным локальным пакетом. Схема БД v6; прежнюю программу со старой схемой нельзя запускать поверх неё. Реальная проверка GitHub API с версией 0.2.0 предложила 0.3.0; установленный Electron 0.3.0 подтвердил актуальность. Автоматическая установка неподписанного файла не выполняется.

Остаётся ручная приёмка Windows 11, настоящий DPI 125–150%, длительное наблюдение GPU/памяти и несколько последовательных CAM-операций в одном документе. Для Authenticode нужен реальный сертификат владельца. Эти пункты не отмечены выполненными.

## Границы

Один собственный FireCNC DIN v1, отдельно для точения и фрезерования. Нет готовых PAL/FANUC/SINUMERIK, G20/G94/G95/G96/G97, промышленных циклов, компенсации радиуса/длины, резьбы и подпрограмм. F — мм/мин, токарное X — диаметр. Точение осесимметрично, фрезерование только сверху плоской концевой фрезой, без поднутрений. Зажим/вылет — геометрический учебный регламент, не прочностной расчёт. См. CNC_PROFILE.md и SIMULATION_LIMITS.md.

Итоговая таблица 14 критериев — [ACCEPTANCE.md](ACCEPTANCE.md).

Начало: `npm ci`, `npm run dev`. Ключ: LICENSING_ADMIN_RU.md. Сервер: SERVER_ADMIN_RU.md. Это учебный тренажёр, подключение к реальному станку отсутствует.
