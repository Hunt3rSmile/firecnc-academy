# Статус FireCNC Academy

Обновлено 14 ноября 2026. Рабочая версия: **0.3.0**. Опубликована стабильная учебная **0.2.0**. **Завершены этапы A и B (офлайн Student/Teacher). Этап C реализован частично. Полный продукт A–F не готов.**

Установлен в Omarchy как пакет `firecnc-academy 0.2.0-1`: `/opt/firecnc-academy`, команда `firecnc-academy`, системный desktop-ярлык и иконка. Проверены нативный Wayland-запуск, offline-обработка Ø30, изоляция renderer и целостность 178 файлов пакета. Обычная сборка встраивает открытый ключ владельца из `config/trusted-keys.json`; выданные им лицензии принимаются через настройки. Перед обновлением создана согласованная SQLite-копия; после обновления совпали идентификатор установки, лицензия, профиль, прогресс, попытки и проекты. Закрытого ключа в клиенте нет. Для новой Linux-сборки: `npm run pack:linux`, затем `./bin/install-omarchy`.

GitHub: https://github.com/Hunt3rSmile/firecnc-academy. В 0.2.0 добавлены автоматическая и ручная проверки GitHub Releases; сообщение о новой версии открывает страницу скачивания, установка выполняется пользователем. Общий workflow проверяет и собирает Windows/Linux; публикация выполняется после успешных заданий обеих платформ.

Работает: Electron/React на Linux, SQLite-профиль и сохранение результатов после перезапуска; 6 содержательных уроков (3+3), 12 собственных вопросов, вводный контроль с воспроизводимым разбором; Monaco и собственный DIN/ISO, G0–G3/дуги/G54/состояние; реальное снятие материала r/Z и 2.5D; основные проверки столкновений; 3D/2D, кадр/сброс/обратный пересчёт; шесть заданий с измерением; офлайн Ed25519, owner CLI/PKCS#8, привязка, импорт/экспорт и проверка модулей в main; JSON-экспорт и согласованный SQLite backup.

Проверки 0.3.0: strict typecheck, 111 Vitest и 7 Electron E2E на Linux. Изменения Gemini в 009ec7c проверены: это исправление ASAR-путей Windows. Полный workflow 43602310550 для 0.2.0 прошёл на Windows-2025 и Ubuntu-22.04, включая установщик, переустановку и сохранение данных после удаления. Результаты 0.2.0 не считаются проверкой новой 0.3.0.

В 0.3.0 добавлены собственные схемы и законченная тренировка G90/G91 по точкам для X/Z и X/Y, воспроизводимый seed, разбор каждой точки и восстановление после перезапуска. Рабочий экран упрощён, параметры убраны в раскрываемую панель. Заготовка/патрон при точении и фреза при фрезеровании вращаются по M3/M4 в воспроизведении; M5 и пауза останавливают показ. Камера сохраняет положение между кадрами. Вращение визуально замедлено 20× и не меняет расчёт материала.

Проект v2 содержит размеры заготовки и закрепление; v1 читается с сохранением исходного кода. Проверяется явный учебный регламент: зажим ≥15 мм, вылет ≤60 мм, захват губками ≥5 мм. Это не расчёт сил крепления. Вся форма шести заданий сравнивается с независимым аналитическим эталоном; исправлена чистовая граница кармана. Попытка практики повторно рассчитывается в локальном Node Worker, сохраняет исходник/условия/версию задания/разбор и отображается в прогрессе. БД v3 мигрирует с резервной копией.

**Следующая конкретная задача:** продолжить недостающие части C/D: интерактивная наладка/выбор узлов станка, модели штангенциркуля и микрометра, затем полноценный движок экзамена с таймером и всеми типами вопросов. Довести учебные данные до 24/120/20, затем преподаватель/пакеты, сервер и CAD/CAM. A–F целиком ещё не завершены.

Ещё не сделано: интерактивная мастерская с выбором узлов и разборкой, штангенциркуль/микрометр; 24/120/20 контент, полноценные экзамены/таймер/seed/восстановление, PDF; преподаватель/scrypt/пакеты/мастер восстановления; Fastify activation-server, короткие ключи, места Lab/renew/deactivate; CAD/CAM; Windows 11 ручная приёмка/DPI/подпись и длительные испытания памяти/GPU. Эти функции не показаны как действующие модули.
