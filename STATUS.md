# Статус FireCNC Academy

Обновлено 14 ноября 2026. Публикуемая версия: **0.2.0**. **Завершены этапы A и B (офлайн Student/Teacher). Этап C реализован частично. Полный продукт A–F не готов.**

Установлен в Omarchy как пакет `firecnc-academy 0.2.0-1`: `/opt/firecnc-academy`, команда `firecnc-academy`, системный desktop-ярлык и иконка. Проверены нативный Wayland-запуск, offline-обработка Ø30, изоляция renderer и целостность 178 файлов пакета. Обычная сборка встраивает открытый ключ владельца из `config/trusted-keys.json`; выданные им лицензии принимаются через настройки. Перед обновлением создана согласованная SQLite-копия; после обновления совпали идентификатор установки, лицензия, профиль, прогресс, попытки и проекты. Закрытого ключа в клиенте нет. Для новой Linux-сборки: `npm run pack:linux`, затем `./bin/install-omarchy`.

GitHub: https://github.com/Hunt3rSmile/firecnc-academy. В 0.2.0 добавлены автоматическая и ручная проверки GitHub Releases; сообщение о новой версии открывает страницу скачивания, установка выполняется пользователем. Общий workflow проверяет и собирает Windows/Linux; публикация выполняется после успешных заданий обеих платформ.

Работает: Electron/React на Linux, SQLite-профиль и сохранение результатов после перезапуска; 6 содержательных уроков (3+3), 12 собственных вопросов, вводный контроль с воспроизводимым разбором; Monaco и собственный DIN/ISO, G0–G3/дуги/G54/состояние; реальное снятие материала r/Z и 2.5D; основные проверки столкновений; 3D/2D, кадр/сброс/обратный пересчёт; шесть заданий с измерением; офлайн Ed25519, owner CLI/PKCS#8, привязка, импорт/экспорт и проверка модулей в main; JSON-экспорт и согласованный SQLite backup.

Проверки: strict typecheck, 98 Vitest, четыре Electron E2E, аналитические эталоны, benchmark. Подготовлен Linux runtime и Windows CI. Упаковка/проверка пакета имеет отдельный отчёт `test-results/packaged-report.json`; Windows-сборки в этой сессии не выполнялись. Не считать наличие CI подтверждением Windows-приёмки.

**Следующая конкретная задача C:** проект v2 с явными параметрами заготовки/крепления/инструментов и миграцией v1; геометрическая последовательность наладки и тесты недостаточного зажима/вылета. Затем размерные схемы, проверка всей целевой области и сохранение практической попытки. Сейчас заготовки/геометрия инструментов фиксированы, оценивание использует указанные пробы, воспроизведение идёт по целым кадрам.

Ещё не сделано: интерактивная мастерская с выбором узлов и разборкой, настраиваемые заготовки/закрепление, полная геометрическая оценка; штангенциркуль/микрометр; 24/120/20 контент, полноценные экзамены/таймер/seed/восстановление, PDF; преподаватель/scrypt/пакеты/мастер восстановления; Fastify activation-server, короткие ключи, места Lab/renew/deactivate; CAD/CAM; Windows установка/обновление/удаление/подпись и длительные испытания памяти/GPU. Эти функции не показаны как действующие модули.
