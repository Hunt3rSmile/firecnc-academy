# Статус FireCNC Academy

Обновлено 14 ноября 2026. Рабочая версия **0.3.0**; опубликована **0.2.0**. Полный объём A–F ещё не принят. Изменение Gemini 009ec7c сохранено: оно исправляет ASAR-пути на Windows.

## Работающие сценарии

- A: локальный профиль SQLite, содержательный урок, контроль и разбор, сохранение после перезапуска; редактор Monaco, G0/G1 и согласованная 2D-траектория.
- B: Ed25519 FCNC1, выпуск/проверка/импорт/экспорт офлайн-лицензии Student/Teacher, привязка к случайной устойчивой установке, проверка прав в IPC, отказ подделке без замены действующего файла. Закрытый ключ отсутствует в клиентском комплекте. Lab выпускается сервером с учётом мест; офлайн CLI Lab не выдаёт.
- C: учебные интерпретаторы точения/фрезерования G0–G3, G54, модальное состояние; реальное изменение r/Z-материала и 2.5D-поля высот; заготовка/крепление в проекте v2; столкновения и восстановление префикса программы; независимая аналитическая проверка полной формы. 20 заданий (10+10), размерные схемы, сохранённые попытки. Шпиндель/заготовка при точении и фреза при фрезеровании вращаются по состоянию M3/M4; пауза/M5 останавливают показ. Вращение замедлено 20× и не определяет расчёт.
- D: 24 собственных урока (12+12), 120 разных вопросов (60+60), все 8 типов ответов; шесть определений экзаменов, настройка тем/времени/порога/seed, снимки вопросов и порядка, автосохранение, восстановление таймера, разбор и рекомендации. Учебные штангенциркуль 0,05 мм и микрометр 0,01 мм: объяснение, тренировка, вопрос, контрольная серия. JSON и PDF-отчёт доступны после истечения лицензии.
- E: локальный режим преподавателя: scrypt N32768/r8/p1 с индивидуальной солью, без пароля по умолчанию; сеанс 30 минут; создание профилей, вопросов/тестов/геометрических заданий; версии и транзакционный импорт/экспорт JSON-пакета. Пример решения проверяется в отдельном Node Worker; исполняемый код из пакета не запускается. Пароль не добавляет модуль teacher к Student-лицензии.

## Границы

Один собственный FireCNC DIN v1, отдельно для точения и фрезерования. Нет поддержки PAL/FANUC/SINUMERIK, циклов, G20/G94/G95/G96/G97, компенсации радиуса/длины, резьбы, подпрограмм и управления оборудованием. F — мм/мин, токарное X — диаметр. Точение осесимметрично; фрезерование только сверху плоской концевой фрезой, без поднутрений. Неподдерживаемые команды останавливают программу. Поле высот отклоняет боковой слой выше режущей длины фрезы. Зажим/вылет — геометрический учебный регламент, не расчёт прочности.

Старт: `npm ci`, `npm run dev`. Ключ владельца: README/LICENSING_ADMIN_RU. Локальный тест: `npm run license:dev` и импорт `.local/development.fcnclic`. Полный статус проверок будет обновлён после текущего прогона.
