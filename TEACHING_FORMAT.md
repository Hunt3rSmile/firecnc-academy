# Учебный пакет v1

Обычный UTF-8 JSON, расширение `.fcnccontent`, максимум 2 МБ. Без архивов, HTML, скриптов и внешних assets. Корневые поля: `format: "firecnc-teaching"`, `version: 1`, `title`, массивы `questions`, `exams`, `exercises`. Схемы находятся в packages/learning/src/teaching.ts, exams.ts, exercises.ts.

Собственные устойчивые ID начинаются с `custom-`, затем строчные латинские буквы/цифры/дефисы. Каждый материал имеет целую положительную `version`. Для изменения увеличьте версию; равная версия с другим содержимым и откат версии отвергаются. Весь импорт транзакционен, ошибка оставляет прежние данные. Новые вопросы/упражнения ссылаются на существующий урок и свой профиль обработки. Пакет не может менять доверенные ключи, запускать код или выдавать права.

Вопрос: id, version, course, lessonId, prompt, explanation, mistake, profile, sourceIds и поля своего типа. Поддержаны single, multiple (только полный набор), numeric (единица/допуск), order, node, program-result, program-error, measurement. Семантика программных вопросов проверяется ядром; показания приборов должны входить в диапазон модели. В UI редактор поддерживает один/несколько/число; все типы доступны в раскрываемом редакторе формата.

Экзамен: id/version/title/course/count/durationSeconds/passingScore/topics/hints/maxAttempts. Необязательный `questionIds` задаёт точный набор доступных вопросов; сохраняется случайный порядок выбранного состава. Состав попытки копируется целиком. Обновление/импорт банка не меняет уже сохранённый разбор. Тесты преподавателя появляются в разделе «Экзамены».

Задание: фиксированный профиль `firecnc-din-v1-turning` либо `...-milling`, заготовка/закрепление и инструменты базового набора, исходник/начальный исходник, аналитическая цель, контрольные измерения и прозрачная оценка 40% форма + 30% размеры + 30% безопасность (в метаданных geometry=70/safety=30). Критическое нарушение — 0. Импортируемый пример решения прогоняется в ограниченном Node Worker; он обязан действительно получить цель, а не только содержать нужные слова. Размеры сравниваются с погрешностью сетки. Для первого формата собственные задания используют Ø40×60 и плиту 60×40×15; другие параметры доступны в свободном проекте.

Одновременно хранится до 200 собственных вопросов, 30 тестов, 20 заданий; встроенный банк не заменяется. В БД остаются редакции. Согласованная резервная копия SQLite включает профили/прогресс/материалы, экспорт пакета — только материалы. Экспорт после истечения teacher-лицензии разрешён при входе с ранее настроенным паролем. Запись требует действующего модуля teacher и 30-минутного сеанса с паролем scrypt; локальная роль не является правом лицензии.
