# Начало работы с FireCNC Academy 0.3

Готовые файлы Windows и Linux находятся в [GitHub Releases](https://github.com/Hunt3rSmile/firecnc-academy/releases/latest). Node.js, npm и исходники на учебном компьютере не нужны.

## Установка

Windows x64: скачайте `setup-x64.exe` и пройдите установку либо запустите `portable-x64.exe`. Текущие сборки не подписаны сертификатом Authenticode. Переустановка и удаление установщиком сохраняют учебные данные. Автоматические проверки выполняются на Windows Server 2025; ручные Windows 11 и DPI 125–150% ещё требуют приёмки.

Linux x64: используйте AppImage либо распакуйте tar.gz и запустите `firecnc-academy`. Для AppImage задайте право исполнения. В Omarchy установленное приложение открывается через Super+Space → FireCNC Academy; пакет из исходников ставится командой `./bin/install-omarchy`. Если FUSE недоступен, AppImage поддерживает `APPIMAGE_EXTRACT_AND_RUN=1 ./имя.AppImage`.

## Как вставить ключ

1. Откройте «Настройки и лицензия».
2. Нажмите «Импорт .fcnclic…» и выберите выданный владельцем файл. Либо вставьте целую строку `FCNC1.…` в поле «Строка лицензии» и нажмите «Проверить и активировать».
3. Убедитесь, что показано «Лицензия действует», верны владелец, срок и модули.

Интернет для файла не нужен. Повреждённый импорт сохраняет прежнюю лицензию. Для привязанного файла сначала экспортируйте запрос установки из настроек и передайте владельцу. Если выдан короткий ключ `FCNC-…`, раскройте серверную активацию и укажите адрес сервера владельца; такой ключ требует связи при активации/продлении. Непросроченный lease затем работает автономно до указанного срока.

Модуль `cadcam` добавляется владельцем в подписанную лицензию отдельно; старый Teacher-файл с шестью модулями его не содержит. Пароль преподавателя также не добавляет лицензионных модулей. Без активации доступны вводный урок, небольшая проверка и два неизменённых примера обработки.

## Первый учебный сценарий

Откройте вводный урок, прочитайте объяснение, выполните упражнение и отметьте урок пройденным. Пройдите проверку и прочитайте разбор. После закрытия и запуска прогресс сохранится.

В «Редакторе и симуляторе» нажмите **«Запустить»**: программа будет воспроизводиться по кадрам, материал изменится, заготовка с патроном при точении или фреза при фрезеровании будут вращаться. Вращение намеренно замедлено 20 раз; M5 и пауза останавливают его. Исходный токарный пример даёт Ø30 мм на Z−15; фрезерный — глубину 3 мм в X30 Y20.

«Пауза», «Кадр», сброс и ползунок управляют воспроизведением. При возврате пересчитываются инструмент и материал. Быстрый полный расчёт находится в «Ещё» → «Рассчитать». Параметры заготовки/крепления и файлы находятся в раскрываемой панели проекта. Ошибка показывает строку, причину и предложенное исправление.

В курсах есть тренировка координат: для каждой точки отдельно выбирается G90 или G91. В точении X задаётся диаметром; при G91 вводите изменение диаметра. Приборы тренируют чтение настоящих согласованных шкал. Экзамены сохраняют точный состав и ответы; **время идёт и при закрытой программе**. Подробный разбор экзамена доступен после завершения.

В мастерской выберите узел, изучите его назначение и пройдите шесть шагов наладки. В CAD/CAM задайте одну из четырёх операций, отредактируйте размеры, нажмите «Построить и проверить», затем откройте результат в симуляторе. Ограничения операций показаны рядом с вводом; дуги CAD пока не означают поддержку произвольного профиля CAM.

## Проекты и данные

«Сохранить проект» сохраняет программу с исходными условиями в SQLite. Обычный файл .nc и учебный .fcncproject экспортируются отдельно. Это профиль тренажёра; программы не подготовлены к передаче на реальное оборудование.

Каталог данных: Windows — `%APPDATA%\FireCNC Academy`, Linux — `~/.config/FireCNC Academy`. Данные лежат вне программы. Используйте «Настройки и лицензия» → «Резервная копия SQLite…»: согласованный снимок учитывает WAL. Копирование одного живого .sqlite не заменяет эту команду.

Для восстановления нажмите «Восстановить резервную копию…», выберите .sqlite и проверьте подтверждение. Приложение проверяет формат/целостность/учебные записи, сохраняет текущую БД как `before-restore-*.sqlite` в каталоге данных, восстанавливает копию и перезапускается. Повреждённый файл не заменяет текущую БД. Восстановление возвращает всё состояние копии, включая профили и привязку установки; более новые изменения останутся в защитной копии.

Истечение лицензии не удаляет данные и не мешает просмотру/экспорту собственных результатов JSON и завершённых экзаменов PDF. Новые лицензируемые действия блокируются. При откате системного времени исправьте дату или обратитесь к владельцу. Экспорт диагностики маскирует секреты и не включает ответы, программы или полный токен.

Приложение проверяет новые выпуски при запуске и раз в шесть часов. Оно сообщает о версии и открывает страницу загрузки; установка выполняется пользователем. Проверка отключается в настройках и не нужна для обучения.

## Управление и справка

Камера: вращение мышью, колесо — масштаб, «К детали» — возврат вида. При недоступном WebGL остаётся 2D. Ctrl+F — поиск, Ctrl+H — замена, Ctrl+Z — отмена, Ctrl+Shift+Z — повтор, Ctrl+S — сохранить учебный проект. Пробел в редакторе вводит пробел.

Точная семантика — CNC_PROFILE.md, модель/точность — SIMULATION_LIMITS.md, выполненные испытания — TESTING.md. В приложении откройте справку для ограничений учебного профиля.
