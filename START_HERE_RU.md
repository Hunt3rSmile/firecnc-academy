# Начало работы на Windows

Это учебная версия: завершены A/B, часть C. Полная приёмка Windows ещё не выполнена. Полученные через CI portable/installer нужно проверить по TESTING.md перед распространением в колледже. Для установки готового пакета Node.js и исходный код не требуются.

1. Запустите portable `.exe` либо установщик `setup-x64.exe`. Подпись Windows возможна только с настоящим сертификатом владельца; текущая конфигурация допускает неподписанный пакет.
2. На главной выберите «Продолжить обучение». Прочтите «Оси токарного станка», откройте разбор и отметьте урок пройденным.
3. Пройдите вводную проверку. Разбор и ответы сохраняются; после закрытия приложения откройте «Мой прогресс».
4. В симуляторе нажмите «Рассчитать», затем «Измерить». Для токарного примера диаметр на Z−15 равен 30 мм; для фрезерного глубина в X30 Y20 — 3 мм.
5. Чтобы выполнять собственные программы и продолжать курс, импортируйте выданный владельцем файл `.fcnclic` в «Настройки и лицензия». Можно вставить строку FCNC1. Интернет для этого не нужен.
6. Для привязанной лицензии сначала экспортируйте «Запрос установки» и передайте владельцу. После переустановки ОС или утраты каталога данных запросите перевыпуск.

В демо доступны только исходные примеры. Изменённый текст не запускается без лицензии с модулем соответствующего типа обработки. Локальное изменение роли или настроек не меняет подписанные модули.

«Сохранить проект» записывает программу и параметры в локальную БД. «Файл…» сохраняет обычный текст `.nc` отдельно. «Экспорт проекта…» сохраняет `.fcncproject`. Не отправляйте эти программы на реальный станок: это профиль учебного тренажёра с описанными упрощениями.

Рабочие данные: `%APPDATA%\FireCNC Academy\academy.sqlite` (Electron userData). Сохраните резервную копию кнопкой в настройках: она использует SQLite Backup API и учитывает WAL. Не копируйте один открытый файл `.sqlite`, игнорируя `-wal`.

Для ручного восстановления **при полностью закрытом приложении** сохраните текущий каталог данных целиком, затем замените БД согласованной резервной копией. Старые `academy.sqlite-wal`/`-shm` должны остаться в сохранённом старом каталоге, а не рядом с восстановленной БД. Не удаляйте единственный экземпляр своих данных. Автоматический мастер восстановления ещё не реализован; проверенный сценарий восстановления на копии описан в TESTING.md.

Истечение лицензии сохраняет проекты, историю и экспорт JSON. Срочная лицензия использует системное время; при заметном откате часов восстановите дату либо обратитесь к владельцу. Бессрочную автономную лицензию невозможно мгновенно отозвать на изолированном компьютере.

Управление: мышь для камеры, колесо для масштаба, «К детали» для возврата вида; 2D работает без WebGL. «Кадр» и ползунок воспроизводят материал с начала. При ошибке исправьте указанную строку и пересчитайте. Пробел в редакторе вводит пробел. Ctrl+F — поиск, Ctrl+H — замена, Ctrl+Z — отмена, Ctrl+Shift+Z — повтор, Ctrl+S — сохранение учебного проекта.
