# Архитектура

Один автономный Electron desktop и один отдельный Fastify activation-server. npm workspaces, один lock-файл. Для уроков, обработки и экзаменов локальный HTTP-сервис не нужен.

| Часть | Ответственность |
|---|---|
| cnc-core | Токены с позициями/исходным написанием, кадры, модальные группы, атомарное состояние, геометрия G0–G3 и MachineEvent. Без DOM, React, Electron, файлов и сети. |
| simulation | r/Z-занятость, XY-поле высот, геометрия инструмента/крепления, проверка движения, съём и измерения. Three.js не участвует в расчёте. |
| learning/content | Версионируемые уроки, восемь типов вопросов, снимки экзамена, измерительные приборы, наладка, независимые аналитические цели и оценивание всей формы. Контент не содержит исполняемого кода. |
| contracts | Узкий типизированный API, схемы проектов и единая матрица модулей. |
| licensing | FCNC1, строгий JSON, Ed25519, общее кодирование/подпись/проверка, ID ключа и установки, нормализация короткого ключа. Node crypto; доверенная часть. |
| license-issuer | Отдельная утилита владельца, PKCS#8, выпуск/проверка/журнал. Секреты не пакуются клиенту. |
| desktop | Sender/schema/permission-проверки IPC, SQLite, безопасные файловые диалоги, офлайн/онлайн лицензия, пароль преподавателя, печать локального PDF. |
| ui | React, Monaco, собственные SVG/Canvas/Three.js, управление воспроизведением. Sandbox, без Node.js. |
| activation-server | Один Fastify/SQLite экземпляр, короткие ключи, места Lab, подписанные lease, секреты установок по хешу, административный API и CLI. Поставляется отдельно. |

Текст → токены → кадр → новое модальное состояние → событие → геометрическая проверка/материал → отображение. Исходный ошибочный кадр не применяется частично. При аварии восстанавливается начало кадра вместе с материалом. Обратный переход детерминированно воспроизводит префикс из исходной заготовки. FPS и визуальное вращение не меняют вычисления. M0 останавливает пошаговое воспроизведение; «Рассчитать» проверяет весь текст. M2/M30 завершают, выключают шпиндель и СОЖ.

Сложный расчёт UI выполняет Web Worker по типизированному протоколу. Итог практики main независимо пересчитывает в Node Worker из ASAR: renderer не присылает доверенную оценку. Пакеты преподавателя проверяются в отдельном Node Worker. Ограничены память (128 MiB old generation), время (30 с), число сегментов/ячеек; отмена завершает worker.

`firecnc://app/` разрешает только GET внутри dist/ui. CSP запрещает произвольные script/connect/object. Monaco, шрифты и workers локальны. contextIsolation/sandbox включены, nodeIntegration выключен; навигация/новые окна/разрешения браузера запрещены. Preload не даёт универсального invoke, файлового пути или shell. IPC проверяет sender, mainFrame, URL, схему, размер и право на новое действие. Чтение результатов и экспорт доступны после окончания лицензии. Ограниченный одноразовый `firecnc://report/<uuid>` обслуживает доверенный HTML отчёта в отдельном скрытом sandbox-окне; шрифт встроен, внешних ресурсов и скриптов нет.

SQLite schema v6: profiles, progress, attempts, projects, coordinate_attempts, practice_attempts, measurement_attempts, exams, teaching_content, audit, settings. Миграции транзакционны; перед изменением существующей БД создаётся согласованная Backup API-копия. Более новая БД отклоняется. Каждый экзамен сохраняет вопросы/версии/порядок/ответы/seed/дедлайн целиком. Новая редакция банка не переписывает прошлый разбор. Экспорт истории полный; экран ограничивается последними 100 попытками. Учебные редакции хранятся отдельно, импорт всей порции транзакционен. Профили локальны и не являются защитой от администратора ОС.

Проект v2 сохраняет исходник, станок, явную заготовку/крепление, G54, сетку и `toolSetId=firecnc-basic-v1`. v1 мигрирует с прежними исходными условиями. Геометрия набора 1/2 описана в SIMULATION_LIMITS. Учебный регламент крепления проверяет геометрию; силы и прочность не вычисляются.

Срок экзамена — абсолютный UTC-дедлайн, идёт при закрытой программе. Последнее наблюдавшееся время не уменьшается внутри попытки. Это локальный учебный контроль, не независимая защищённая аттестация.

Сессия преподавателя живёт только в памяти 30 минут. Пароль scrypt N32768/r8/p1, соль 32 байта, результат 64 байта, maxmem 64 MiB. Каждый write требует и сеанс, и проверенный модуль teacher. Изменение роли/настроек не добавляет модулей.

Онлайн-клиент сохраняет случайный секрет установки перед первым запросом; повтор после потери ответа идемпотентен. Сервер хранит только хеши короткого ключа и этого секрета. Проверенный Ed25519 lease использует тот же FCNC1. Резервирование места учитывает ещё действующий автономный lease даже после deactivate/reset. Приватный ключ/административный токен есть только у владельца/сервера. Основной процесс использует safeStorage ОС, если доступно; Linux basic_text не считается защищённым backend. Fallback — пользовательская БД 0600 в каталоге 0700, явно показан в UI.

Host Node и Electron Node различаются. better-sqlite3 13.2.0 использует Node-API; всё равно проверяется настоящий Electron. postinstall загружает Electron и запускает electron-rebuild; `.node` извлекается из ASAR. Клиент не требует установленного Node/npm. Сервер запускается отдельно с Node 24 LTS; инструкции — SERVER_ADMIN_RU.md.
